## [1] Download the Plugin

To get started, you will need to [download](https://www.spigotmc.org/resources/electionsplus-add-democracy-to-your-server.93463/) the plugin from the SpigotMC homepage.

<Steps>
  <Step title="Download the plugin">
    Visit the [SpigotMC page](https://www.spigotmc.org/resources/electionsplus-add-democracy-to-your-server.93463/) and download the latest version of ElectionsPlus.
  </Step>
  
  <Step title="Place in plugins folder">
    Simply drag and drop the downloaded JAR file into your server's `plugins` folder. 
    
    <Info>
      If you're using a server hosting website, the process should be similar except you should be navigating through an FTP client.
    </Info>
  </Step>
  
  <Step title="Start / Restart Your Server">
    Simply initiate a restart or boot up your server for the plugin to be installed and loaded.
  </Step>
</Steps>
