## Buying the plugin

The first thing to do is buying the plugin. You can purchase it on:
- [SpigotMC](https://www.spigotmc.org/resources/103552/)
- [BuiltByBit](https://builtbybit.com/resources/configsync.24276/)

## Installing the plugin

The plugin doesn't require any other plugin, you only need to put it into your `/plugins/` folder and fill in your MySQL details.

<Warning>
Remember to read our [Terms of Service](/configsync/tos).
</Warning>

## Next Steps

After installing the plugin, you'll need to:
1. Configure your MySQL database connection
2. Set up the files you want to sync
3. Configure the scheduler settings

Check out the [Configuration](/configsync/configuration) guide for detailed instructions.
