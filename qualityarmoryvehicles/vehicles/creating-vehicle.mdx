# Creating a Vehicle

For creating a vehicle I suggest editing a premade configuration.

These are all settings.

## vehicle_type

The vehicle type.  
Available types: Car, Plane, Boat, Helicopter, Train, Drill, Tractor, Carriage.

Carriages have no engine and are pulled by hitched animals. See [Carriages](/qualityarmoryvehicles/vehicles/carriages) for their extra options.

## name

The vehicle name, it must be unique.

## id

The vehicle id, it must be unique.

## displayname

The vehicle display name.

## center

A vector displaying the center of that vehicle.

## passagers

A list of vectors representing the position of the passengers' seats.

Seats keep the order of this list, so the first vector is passenger seat `0`, the second is seat `1`, and so on. Attachments use these indexes in their `seat` option.

<Note>
The whole part of Y (from 0 to 2) is read as the seat size and does not move the seat. Only the rest is a vertical offset. For example, `1` means no offset, `1.5` means +0.5, `3` means +1 and `-0.5` means -0.5.
</Note>

## stopMeleeDamage

If set to true, the vehicle will not be damaged by guns.

## RequiresFuel

If set to true, the vehicle will require the fuel for being used.

## hitbox

The shape of the vehicle, as one box or a list of boxes. If it is missing, the hitbox is generated from the seats and the vehicle size. See [Hitboxes](/qualityarmoryvehicles/vehicles/hitboxes).

## widthOffset

The width of the generated hitbox. It is only used when the `hitbox` option is missing.

## heightOffset

The height of the generated hitbox. It is only used when the `hitbox` option is missing.

## front_vector_offset

How far the vehicle reaches toward the front. It is used to generate the hitbox.

## back_vector_offset

How far the vehicle reaches toward the back. It is used to generate the hitbox.

## vehicle_texture_material

The item of the vehicle

## maxHealth

The max health of the vehicle

## cost

The cost of the vehicle in the shop. To disable it, set it to -1.

## InputManager

A map of registered inputs.

Input types: HONK, SIREN, MININUKE_BOMBER, TNT_BOMBER, 40MM_LAUNCHER, BULLETS_556.

## ItemLore

A list of strings for the item lore

## TurnSpeedInRadians

The turn speed

## trunksize

The size of how many items can the trunk contain.

## allowedInShop

If set to true, players will be able to buy the vehicle from the shop.

## maxAcceleration

The max speed for the vehicle

## baseAcceleration

The base speed for the vehicle

## maxReverseAcceleration

The max reverse speed for the vehicle

## canJumpOnBlocks

If set to true, the vehicle will be able to jump on blocks

## jumpHeight

The height of how many blocks can the vehicle jump

## model.ModelSize

Current available options: BABY_ARMORSTAND_HEAD, ADULT_ARMORSTAND_HEAD, ADULT_ARMORSTAND_HAND, TURTLE

## model.SeatsSize

The size of the passenger seats. It uses the same options as `model.ModelSize` and defaults to the value of `model.ModelSize`.

## rotationMultiplier

A number that is multiplied by the calculated rotation.

## sound

The id of the sound that is played while driving

## soundVolume

The volume of the sound

## driverseat.Offset

The vector that represents the position of the driver seat.

<Warning>
With `unsafe.separateModelAndDriver` enabled, a negative Y would make the vehicle float, so the plugin uses `0` instead.
</Warning>

## attachments

Extra model parts that follow the vehicle, such as wheels or turrets. See [Attachments](/qualityarmoryvehicles/vehicles/attachments).

<Info>
The old `complexadditions` section is converted to attachments when the vehicle is loaded. The `t50tankcannon` addition becomes a turret.
</Info>
