# Getting Started

Installing the plugin is very simple. There are only 4 steps to do.

* [ ] Buy the plugin
* [ ] Drag the jar in the plugins folder
* [ ] Install [ProtocolLib](https://www.spigotmc.org/resources/protocollib.1997/)
* [ ] Start the server

## Supported servers

QualityArmoryVehicles runs on Spigot, Paper and their forks, from Minecraft 1.9 up to the latest releases.

Since version 2.6 the plugin also supports [Folia](https://papermc.io/software/folia). Each vehicle is ticked by the region that owns it, so no extra setup is needed.
